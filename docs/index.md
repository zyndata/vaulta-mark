# VaultaMark

**Encrypted bookmarks that never touch your omnibox — synced through your own Google Drive.**

VaultaMark is a Manifest V3 Chrome extension that keeps bookmarks in a password-encrypted vault
stored completely outside Chrome's bookmark and history systems, so vaulted URLs can never appear in
address-bar autocomplete.

This site exists to serve one document at a stable address. Everything else lives in the repository.

- **[Privacy policy](PRIVACY)** — what VaultaMark collects, which is nothing.
- **[Source code, issues and releases](https://github.com/zyndata/vaulta-mark)** — GPL-3.0-only.
- **[Security policy](https://github.com/zyndata/vaulta-mark/blob/main/SECURITY.md)** — how to report
  a vulnerability privately, and why there is no password recovery.

The technical documentation — the architecture, the cryptography, the threat model — is read on
GitHub rather than here: [ARCHITECTURE.md](https://github.com/zyndata/vaulta-mark/blob/main/docs/ARCHITECTURE.md)
and [THREAT_MODEL.md](https://github.com/zyndata/vaulta-mark/blob/main/docs/THREAT_MODEL.md).
